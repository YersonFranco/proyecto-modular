Comparación

Aspecto CSS propio Bootstrap
Columnas Se controlan con grid-template-columns y media queries. Se controlan con row-cols-* en la fila.
Separación Se define con gap en CSS. Se aplica con g-4 en la fila y p-3 en el contenido.
Control Permite decidir cada regla y cada breakpoint. Permite maquetar rápido con clases listas; usa los breakpoints del framework.
